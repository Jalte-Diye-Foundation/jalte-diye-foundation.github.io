# Security Policy

Thank you for helping keep this project and its users safe.

## Supported Scope

This policy applies to the website source code in this repository.

## Reporting A Vulnerability

Please do not open public issues for security vulnerabilities.

Report vulnerabilities privately by email:

- contact@jaltediyefoundation.org

Include:

- A clear description of the issue.
- Steps to reproduce.
- Potential impact.
- Suggested fix (if available).

## Response Process

- Initial acknowledgment target: within 7 days.
- Triage and severity assessment: as quickly as possible.
- Fix timeline depends on severity and complexity.

When valid issues are fixed, maintainers will coordinate disclosure and publish
relevant updates.

## Security Best Practices For Contributors

- Never commit secrets, tokens, or credentials.
- Avoid adding external scripts without review.
- Keep dependencies updated when applicable.
- Report suspicious behavior or compromised accounts immediately.
