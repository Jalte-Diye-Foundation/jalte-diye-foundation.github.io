# Task Management

## Backlog Intake

Create one issue per task using the Task issue template.

Required metadata:

- Team owner
- Priority
- Acceptance criteria
- Dependencies

## Sprint Planning

- Select tasks from backlog.
- Assign owners.
- Set target branch.
- Confirm dependencies.

## Execution Rules

- One PR should map to one issue.
- Link PR to issue with closing keywords.
- Keep PRs small and reviewable.

## Review Rules

- At least one reviewer required.
- Deployment-impacting changes need Team 2 review.
- Documentation-impacting changes need Team 3 review.

## Completion Rules

Close the task only after merge and verification.
