# Contribution Workflow

## Step 1: Open Or Pick An Issue

- Use issue templates.
- Confirm scope and acceptance criteria.

## Step 2: Create A Working Branch

Create your branch from the relevant team branch.

## Step 3: Implement And Test

- Run local server.
- Validate desktop and mobile behavior.
- Check links and content.

## Step 4: Open Pull Request

- Fill out PR template.
- Link related issue.
- Add screenshots for UI changes.

## Step 5: Review And Merge

- Address review comments.
- Merge into role branch.
- Maintainers merge role branch into `main`.

## Step 6: Document Outcomes

- Update docs when behavior changes.
- Add release/deployment notes when needed.
