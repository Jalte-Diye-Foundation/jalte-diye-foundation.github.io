# Support

## How To Get Help

For project questions, help requests, and general support:

- Open a GitHub issue in this repository.
- Use GitHub Discussions if enabled.
- Email: contact@jaltediyefoundation.org

## What To Include

To help maintainers respond faster, include:

- The page or file affected.
- Steps to reproduce (for bugs).
- Expected behavior and actual behavior.
- Browser and device details for UI issues.
- Screenshots where relevant.

## Security Issues

For security vulnerabilities, do not open a public issue.

Please follow `SECURITY.md` and report privately.
